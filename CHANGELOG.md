# Changelog

## 0.1.0 — 2026-10-15

First independent **GR-DLC** preview release, continuing GR Mod `0.6.4-film120-jpg-w2` at commit `2cb491b`.

- Establish the independent project, Chinese/English README, complete source credits and contribution guidance, preserving upstream Git history and GPL-2.0-only.
- Rename application UI, window titles, app bundles and Windows metadata to GR-DLC.
- Use a separate GR-DLC data directory; document optional migration of the existing GR Mod store.
- Retain the current firmware, RAW, ratio, film conversion, JPEG identity and W2 algorithms. Existing project formats, firmware markers and internal APIs remain compatible.
- Include the 120-entry catalogue and icons; third-party LUTs, fitted parameters, firmware and personal photos remain outside public distributions.

### Validation scope

The IIIx HDF 1.60 feature set has the earlier hardware feedback documented in `docs/`. GR IV 1.11 independent slots have software/native-function validation and still require camera testing. No claim is made that all 120 films or every feature combination were shot on a camera.

Historical T4, T6, C1, J1 and W2 reports retain their original names and dates in the repository. The independent app version is not a camera firmware version.
